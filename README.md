# SEO Analytics & Business Intelligence Dashboard

An interactive business intelligence dashboard developed using Python, Streamlit, and Plotly to analyze website traffic, user engagement, and behavioural patterns.

## Project Objectives

- Analyze website performance through key business metrics.
- Examine traffic sources and user engagement.
- Segment user sessions using K-Means clustering.
- Identify patterns that can support marketing and business decisions.
- Present analytical findings through interactive visualizations.

## Key Features

- Executive KPI dashboard
- Traffic source and bounce rate analysis
- User segmentation using K-Means clustering
- Custom Engagement Score and User Value Score metrics
- Session quality and engagement analysis
- Feature correlation heatmap

## Technology Stack

Python, Pandas, NumPy, Streamlit, Plotly, Scikit-learn

## Business Applications

The dashboard demonstrates how website analytics can be transformed into accessible insights to support audience segmentation, marketing performance analysis, and data-informed decision-making.
